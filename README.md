# Conexão Net — Landing Page

Landing page de fibra óptica da **Conexão Net**, construída com a identidade visual da marca (globo azul com detalhe verde, tipografia "CONEXÃO" em azul e "NET" em verde).

## Sobre

Página única (`index.html`) totalmente autossuficiente — todo o CSS, JavaScript e ilustrações (incluindo o logo, recriado em SVG inline) estão embutidos no próprio arquivo. Não há dependências externas, então basta abrir o `index.html` no navegador.

### Seções
- **Header** fixo com navegação e CTA
- **Hero** com globo animado e destaque de velocidade
- **Faixa de confiança** com números
- **Planos** de fibra (400MB, 600MB, 800MB e 1GB)
- **Vantagens** da Conexão Net
- **Streaming / entretenimento**
- **Consulta de cobertura** com formulário integrado ao WhatsApp
- **Depoimentos** de clientes
- **FAQ** (perguntas frequentes)
- **CTA final** + **rodapé** com contato e redes sociais
- **Botão flutuante de WhatsApp**

Totalmente responsiva (desktop, tablet e mobile).

## Personalização
Os valores de planos, preços, fotos, telefones (`wa.me/55...`), e-mail e CNPJ são **ilustrativos** — ajuste-os no `index.html` com os dados reais da Conexão Net.

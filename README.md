# Atividades-diversas

## Landing Page — Aulas de Inglês

Landing page para captação de leads de aulas de inglês, com visual tecnológico
nas cores azul e vermelho (bandeira dos EUA).

### Destaques
- **Frase de impacto** no topo para prender a atenção do lead.
- **Autoridade**: 15 anos de formação, Exame de Cambridge nota 955, nível C1.
- **Dois métodos**:
  - **Opus Intensivo** — 3 aulas/semana (aprendizado definitivo, longo prazo).
  - **Lotus** — 5 aulas/semana (intensivo rápido).
- **Seção de motivos**: Viagem, Emprego, Preparação para migração.
- **Perguntas frequentes (FAQ)**.
- **Formulário de captura** (via botões de CTA) com: nome, telefone, e-mail e
  motivo (Viagem / Emprego / Preparação para migração).
- **Responsivo** para mobile, com CTA fixo e efeitos visuais (reveal ao rolar,
  gradientes animados, brilho nos botões).

### Como usar
Abra o arquivo `index.html` no navegador. É um arquivo único e autossuficiente
(HTML, CSS e JS embutidos), sem dependências externas.

> Observação: por ser estática, a captura de leads registra os dados no
> `localStorage` e no console do navegador como fallback. Para produção, integre
> o `submit` do formulário (em `index.html`) a um backend, e-mail, CRM ou WhatsApp.

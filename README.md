# Atividades-diversas

## Landing Page Smartyng

Landing page da **Smartyng** — agência de marketing e tecnologia.

- **`index.html`** — página completa e autônoma. Abra direto no navegador ou publique
  em qualquer hospedagem estática. O conteúdo também pode ser colado num bloco
  "HTML personalizado" do WordPress (todo o CSS/JS é escopado no `#smartyng-lp`).
- **`assets/`** — imagens da marca (logo e foto do fundador). Veja `assets/README.md`
  para adicionar a logo (`smartyng-logo.png`) e a foto (`founder.jpg`).

### Logo
A logo tem uma versão **SVG vetorial** embutida na página (sempre nítida, nunca quebra).
Para usar o PNG oficial da Smartyng, basta adicionar `assets/smartyng-logo.png` — ele
é usado automaticamente no lugar do SVG.
